# Atharva Tayade — Portfolio

My personal portfolio and interactive résumé site — built with React + Vite, with content driven from a single data file and animated with Framer Motion.

🔗 **Live:** https://atharvax1.vercel.app

---

## Highlights

- **React + Vite** for a fast dev loop and lean build
- **Framer Motion** for page and element transitions
- Content is data-driven via [`resume_data.json`](./resume_data.json) — edit the data, not the markup
- **Vercel Analytics** for visit insights

## Tech stack

`React` · `Vite` · `JavaScript` · `Framer Motion` · `lucide-react`

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run preview  # preview the build
```
